# StayHealthy

StayHealthy is a static frontend portfolio demo. Open `index.html` in a browser or serve the project directory with a local static web server.

The sign-up and login pages only validate form input. Doctor profiles are fictional, appointment buttons do not create bookings, and reviews are displayed only in the current page; no personal information or submissions are stored. Password recovery requires a future secure backend.

Health articles are educational examples, not individual medical advice. Each article links to its public-health source.
